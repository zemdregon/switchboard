# Security Policy

## Supported versions

The repository has no released software yet. Only the `main` branch is
maintained, and security fixes apply to it.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

- If the repository's **Security** tab shows **Report a vulnerability**, use it.
  This opens a private advisory that only maintainers can see.
- If that option is not available, contact the repository owner,
  @zemdregon (the repository owner on GitHub), by a private GitHub message.

Include what you found, the file or document involved, and steps to reproduce
it if you have them.

## Scope

This repository currently holds documents. Relevant reports include guidance
that would lead an implementer to weaken credential handling, permission
boundaries, or sandboxing, and exposed secrets or credentials in the
repository history.

## Response times

No response or fix time is promised. The project is maintained on a best-effort
basis.
